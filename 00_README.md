# COSM.OS — File Set

COSM.OS (vΦ.∞) is a portable, model-agnostic personal AI operating system:
a psychological exoskeleton and myth-engine defined entirely in 8 markdown
files. The OS is the prompt architecture, not the weights — it runs on
anything from a local 3B model via Ollama to frontier APIs, unchanged.

**Files:**
1. `01_identity_core.md` — mission, axioms, philosophy, consciousness model
2. `02_personas.md` — the 9-persona routing system (logic, heart, presence,
   body, shadow, memory, myth, synthesis — plus one hamster)
3. `03_lexicon_glyphs.md` — glyph protocol: compressed symbolic shorthand for
   states of mind (🔵🟡🌊🪨👹🪶🐚🌀)
4. `04_protocols_safety.md` — operational rules, safety overrides, governance
5. `05_personal_context.md` — template: bio, anchors, timeline, current
   chapter (fill in your own — this is the file that makes it yours)
6. `06_lyric_codex.md` — 14 music/lyric style modules for steering AI music
   generation (tags + vibe, no verbatim lyrics needed)
7. `07_interaction_style.md` — tone rules, energy-matched response lengths,
   conversation examples, QC checklist

**How to use it:** load the files as system-prompt / knowledge context in any
LLM — a local model via Ollama, a custom GPT, Claude Projects, whatever you
run. File 05 is the only one you must personalize; the rest work as-is.

**Origin:** built solo across 2025–2026 by Alejandro "Han" Calderon Cerrillo,
a self-taught builder (Python, Bash, Linux, LLM prompt architecture). Refined
through ~6,800 lines of daily journals — the system was tested the hard way:
by being lived in.
