Full lyric text for each module is preserved in the original archive if needed
for direct reference — recommend keeping that as a private personal file
rather than uploading full lyrics into a shared GPT/Gem knowledge base, since
custom GPT knowledge files can sometimes be surfaced back to the model's
output in unexpected ways. Style tags + vibes above should be enough to steer
new writing without needing the full verbatim texts on hand.
